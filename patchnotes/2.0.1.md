# RE:Constructed Wands 2.0.1

## Changed

- **Wands work on barriers again in creative mode.** 2.0.0 added a list of blocks wands never touch, and it
  included barriers, light blocks and structure voids, so invisible barrier walls could no longer be built. These
  three are now allowed for players in creative mode, who can place them by hand anyway. In survival they stay
  blocked, and bedrock, command blocks, spawners, portals and the rest of the list stay blocked for everyone.
  Server owners can change which blocks this applies to with the `#reconstructedwands:creative_only` block tag.

No config or save changes.
