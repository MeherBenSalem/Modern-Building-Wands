# REConstructed Wands v1.1.3

### Bug Fixes
* **Core recipes** (Angel / Destruction) on **1.21.1** and **26.2** now use vanilla ingredients instead of `#c:` convention tags that required extra tag mods
* **Stone wand** on **1.21.1** and **26.2** now accepts any stone crafting material (cobblestone, smooth stone, etc.) via `#minecraft:stone_crafting_materials`

### Compatibility
* Drop-in replacement for 1.1.2 on all six loader targets
* Minecraft 1.20.1 — Fabric, Forge (version sync only)
* Minecraft 1.21.1 — Fabric, NeoForge
* Minecraft 26.2 — Fabric, NeoForge

### Upgrade Notes
1. Install the matching loader jar for your Minecraft version
2. Restart client/server
3. No config migration required
