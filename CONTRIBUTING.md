# Contributing

Thanks for helping improve RE:Constructed Wands.

## How to contribute

1. Fork the repository and create a branch from `main`.
2. Prefer small, focused changes with a clear purpose.
3. Match existing code style and MultiLoader layout (`1.20.1/`, `1.21.1/`, `26.2/`).
4. Open a pull request describing what changed and why.

## Development

- Java 17 for `1.20.1` (Fabric + Forge)
- Java 21 for `1.21.1` (Fabric + NeoForge)
- Java 25 for `26.2` (Fabric + NeoForge)
- Build a workspace with `./gradlew build` (or `gradlew.bat` on Windows) from that workspace folder
- Shared logic lives in each workspace's `common` module
